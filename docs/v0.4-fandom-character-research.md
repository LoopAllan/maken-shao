# v0.4 MegaTen Wiki 角色爬取與圖片 provenance

> 查閱日期：2026-07-16。指定入口：[`Kei Sagami`](https://megamitensei.fandom.com/wiki/Kei_Sagami)。本文件記錄研究方法、角色集合、版本界線與圖片技術 provenance；不重製 Wiki 全文，也不把技術可下載性描述為再散布授權。

## 集合與方法

- 以 MediaWiki API `action=parse` 讀取 `Kei Sagami`（revision `579942`），確認頁面轉入 `Template:MX`（revision `485157`）。
- `Template:MX` 的 Characters 區塊列出 **Playable 19 頁、Non-playable 9 頁**；`Category:Maken X Characters` 的 `categorymembers` 清單也正好是相同的 **28 頁**。
- 每頁均在 `Appearances` 列出《Maken Shao》，但正文混寫 Dreamcast《Maken X》、PS2《Maken Shao》、PAL 英文版《Maken Shao: Demon Sword》及漫畫；**沒有任何一頁能只憑 Fandom 安全當成 PS2 日版事實來源**。
- 日版姓名、路線、Brain Jack 身分與可操作性只在 Atlus 保存頁或兩套 PS2 日文流程資料另有支持時才提升查證等級；`Maken X English` 名稱、PAL Profile 原句、招式／數值、地域版設計差異及漫畫內容不倒灌日版欄位。
- `wikiNavigationGroup` 原樣保存 19／9 的導航分組；另從各頁原始 wikitext 的正文（排除 `Template:MX`）抽出 **102 條**角色頁明示連結，寫入 `wikiLinkedCharacterIds`。阿基納斯與都柏林博士頁沒有其他角色正文連結。

## 重要辨識修正

- **Lee Fei Chao（リー・フェイチャオ／李飛超）**：男性封劍士，在開場研究所事件中死亡；不是 Brain Jack 宿主。
- **Lee Fei Shan（李 飛扇／李飛扇）**：女性封劍士見習生，既有 PS2 日文流程支持其香港／泰姬瑪哈陵路線宿主身分。初版把兩人混為一筆，本次依 Wiki 的兩個獨立頁並配合既有日文流程證據拆分。

## 角色前置關係與反向顯示

角色詳細頁的關聯區塊不是「同一地圖可獲得角色」。`character-details.json` 以 `prerequisiteCharacterIds` 保存取得該角色時明確需要的**直接角色前置**；頁面再反向查詢哪些角色把目前角色列入此前置欄位。沒有直接依賴者時，頁面明示目前沒有已查證依賴，而不以同地圖角色補位。

目前由 PS2 日文取得流程支持的直接關係為：相模桂 → 安德烈、李飛扇 → 沙爾嘉、拉姆羅德 → 瑪格麗特、阿基納斯 → 巴林卡、巴林卡 → 達爾、巴德萊爾 → 史密斯議員／唐・馬爾卡拉、史密斯議員 → 唐・馬爾卡拉、唐・馬爾卡拉 → 雷。只記直接前置；例如達爾不重複列出已由巴林卡隱含的阿基納斯。

## 圖片選擇與技術 provenance

角色與招式圖片下方不顯示來源、驗證狀態或權利聲明，以免壓縮遊玩內容版面；這些既有 provenance 欄位會與圖片內容描述一併組入圖片 `alt`。結構化原始資料及參考資料頁仍保留完整可查證內容。

- 依使用者指定，角色卡優先採角色頁中的 Wiki 圖片；19 張候選檔名含 `(Shao)`，本站把它們分類為 `game-screenshot`。此命名只是 PS2 版本線索，**不是**官方來源、日版證明或權利證明。其餘圖像分為角色美術或遊戲卡片，不能由檔名確認 PS2 版本。
- 對選定 28 個 File title 執行 `imageinfo`；`extmetadata` 未提供可驗證的 `Artist`、`Credit`、`Source`、`LicenseShortName`、`LicenseUrl`、`UsageTerms`、`Copyrighted` 或 `ImageDescription`。技術 provenance 與著作權 provenance 必須分開。
- API 提供的最大 640px 縮圖實際回應格式是 WebP（原圖寬度不足 640px 時使用該寬度），因此本地檔統一使用 `.webp` 副檔名；資料另保留原始 Wiki 資產的 MIME、尺寸、bytes 與 SHA-1，以及本地縮圖的 SHA-256。
- 重新抓取驗證時，28 個 WebP 縮圖皆與本地 SHA-256 完全相符。以 `format=original` 取回 Wiki 原始資產時，23 個檔案與 API SHA-1／bytes 完全一致；5 個 JPEG（Lee Fu Sho、Lee Fei Chao、Mr. Meteor、J.J. Jones、Hiromitsu Sagami）目前由 CDN 回傳的 bytes 與 API 上傳 metadata 不同，因此標為 `api-metadata-only-current-cdn-byte-mismatch`，不得宣稱原始資產 byte-for-byte 已複核。

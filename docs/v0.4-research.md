# v0.4 角色資料研究紀錄

查證日期：2026-07-16

## 範圍

本階段限定 PS2 日版《魔剣爻》。角色姓名、身分與關係優先採 Atlus 官方網站的 Internet Archive 保存頁；流程位置與 Brain Jack 宿主狀態若需社群攻略補充，必須明示為部分查證。Dreamcast《Maken X》及 PAL 版名稱不得直接移植。

## 直接採用的官方證據

- `atlus-maken-shao-characters-archive`：Atlus 官方角色介紹。正文直接介紹魔劍、相模桂、山城弘；角色名圖像可讀得 `魔剣 / Deus Ex Machina`、`相模桂 / Kei Sagami`、`山城弘 / Kou Yamashiro`。本站只轉述必要事實，並保存已下載的個別角色圖像作為可追溯的離線引用；每張圖均保留來源頁與著作權註記。
- `atlus-maken-shao-correlation-archive`：Atlus 官方相關圖。文字層可查證封劍士一族、金澤總合學術研究所與三業會的組織說明；圖像中未能可靠辨識的個別姓名不據此建檔。
- `game-watch-maken-shao-2001-02-23`：同期新聞獨立確認玩家是魔劍，並透過 Brain Jack 使用不同角色的身體戰鬥。

## 社群流程交叉證據

- `blue-violet-maken-shao-characters`：明列 18 名「ブレインジャックキャラクター」。
- `gamehyoron-maken-shao-route-table` 與 Kentaro 前／後期表：逐區域支持角色取得、互斥選擇與後期強制使用條件。
- 名稱衝突保守處理：`アキナス`（異綴 `アナキス`）、`バデレール`（異綴 `バルデール`）；不把異綴另立角色。

## 角色建檔界線

v0.4 初版建立 22 筆保守角色資料；指定 MegaTen Wiki 研究擴充後，資料集改為其「MX」導覽與 `Category:Maken X Characters` 的 28 個角色頁。其中 17 筆姓名／分組仍可由 Atlus 官方角色頁直接確認；其餘項目保留社群來源層級與版本警語。兩套獨立日文流程資料共同支持 18 名可操作／Brain Jack 分類角色，但這 18 人包含開場強制使用與特定結局路線角色，不能改寫成「18 人都能隨時自由 Brain Jack」。

所有取得位置、互斥選擇與後期角色身分仍按證據標為 `partially-verified`，但產品政策已改為全部直接顯示，不再遮蔽姓名、路線或完整來源。未找到可靠官方羅馬字名單，因此 URL slug 或 PAL 版拼法不作官方英文名。

官方頁的兩個「？」與三種未具名三業會兵士不建立臆測 ID。

## 名稱與圖片呈現規則

- 每筆角色必須有 `nameZhHant`（本站繁中顯示名）、`nameJa`（來源中的日文名）與 `nameEn`（英文欄）。
- `nameEnStatus: official` 只用於官方角色圖中可直接讀到的拉丁字樣；`romanized` 是依日文／漢字名整理的英文字形；`community` 是 MegaTen Wiki 社群頁名。後兩者均不得宣稱為 PS2 日版官方英文名。
- `assets/images/characters/` 現保存 28 張指定 MegaTen Wiki 角色頁的最大 640px 本地 WebP 縮圖。每筆以原始 MIME／尺寸／bytes、下載 URL、File 頁、上傳者、Fandom SHA-1 與本地 SHA-256 完整追蹤；檔名含 `(Shao)` 的 19 張圖只作 PS2 版本線索，不當成官方來源或權利證明，其餘 9 張明示版本未由檔名確認。
- 圖片檔案頁的 API `extmetadata` 沒有提供可驗證的自由授權欄位；站內因此明示著作權未釐清、不主張自由再散布授權，並使用縮圖而非原尺寸資產。
- 28 個本地 WebP 縮圖均可由宣告下載 URL 重抓並通過 SHA-256；原始資產則有 23 筆精確通過 API SHA-1／bytes，5 筆 JPEG 因目前 CDN bytes 與 API metadata 不同而明確標為僅有 API metadata，不作 byte-for-byte 已驗證聲明。

## 著作權與完整顯示

- 保存圖檔僅作離線研究／識別引用；Fandom File 頁未提供可驗證的作者、底層出版來源、權利人或授權，本站不推定這些欄位，也不宣稱擁有或可再散布作品。若權利人要求，應移除本地副本並改為僅保留來源連結。
- 每張圖都要在角色卡標示其 MegaTen Wiki 檔案頁、版本警語與權利說明；不移除來源／著作權識別，也不使用攻略本掃描頁。
- 資料、schema 與驗證器均移除 `spoiler`／`spoilerLevel`；角色卡、搜尋、流程與來源頁直接顯示完整標題、摘要、圖像與正文。
- 逐頁 crawl、角色分類與圖片清單詳見 `docs/v0.4-fandom-character-research.md`。

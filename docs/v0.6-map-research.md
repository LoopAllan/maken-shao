# v0.6 地圖圖鑑研究與素材界線

> 查證日期：2026-07-17
>
> 遊戲事實範圍：日本 PS2《魔剣爻》
>
> 視覺素材範圍：Dreamcast《Maken X》（使用者於 2026-07-17 明確允許作地圖視覺介紹）

## 資料原則

地圖名稱、性質、劇情用途、前置條件、可獲得角色與敵人，只採日本 PS2 資料：GAME瓢論 stage index／序中終盤攻略／分歧表、Kentaro 前後期流程，以及 BLUE VIOLET stage flowchart。Dreamcast 圖片不作為 PS2 路線、敵人或劇情證據。

重訪與旗標變體不重複計圖：倫敦、伊斯坦堡、梵蒂岡、麥加、巴西及紫禁城的不同事件狀態仍視為同一張地圖。維也納雖被 GAME瓢論索引漏列，但在其正文及 BLUE VIOLET 流程圖均為獨立關卡。

GAME瓢論中盤／終盤與 Kentaro 後期流程以仍可存取的原站 URL 作主要資料來源，並在 `sources.json` 保存 `id_` Wayback raw replay 作備援。這可避免一般 Wayback replay 偶發 HTTP 500 時，把存取失敗誤判成內容無法驗證。

## 圖片收錄規則

地圖卡至少需要一張可核對地點歸屬的遊戲圖片，優先順序為：

1. 地球儀上的地圖點；
2. Stage Preview／地圖構造；
3. 標誌性遊戲畫面。

目前 20 張 PS2 地圖均有 Dreamcast 視覺參考，共 57 張本地 WebP。其關聯證據分成兩級：

- 其餘 19 張地圖共 54 張圖片：MegaTen Wiki 地點頁的 `prop=images` 明確列出檔案，且 File title 明示 `Maken X`。
- 崑崙共 3 張圖片：MegaTen Wiki File namespace 的 `Maken X Kunlun location／map／card` 同日同上傳者系列；File title 直接標示地點，但沒有地點頁／`fileusage` 關聯，因此資料以 `file-title-series` 明示較弱的關聯方法，不把圖片當作 PS2 證據。

每張圖保留：

- 關聯頁 URL、revision 與關聯方法；
- File title、File URL 與 revision；
- 原始 CDN URL；
- 原始 PNG MIME、尺寸、bytes、MediaWiki SHA-1、上傳者與時間；
- 本地 WebP 尺寸、bytes 與 SHA-256；
- Dreamcast 版本標示、場景對應說明與權利警語。

本地檔只使用最長邊不超過 640px 的 WebP，作地圖辨識與評論。使用者的素材決策不是權利人的再散布授權；網站不主張圖像權利或自由再散布授權。

地圖圖像下方不再顯示版本、來源鏈、完整性或權利聲明；上述欄位與遊戲畫面描述一併組入圖片 `alt`，讓可見版面只保留地圖、劇情、構造、解鎖、角色及敵人等遊玩資訊。結構化資料與參考資料頁仍保留完整 provenance。

## 連結規則

全站地圖名稱採最長別名優先及 Latin／片假名字詞邊界。連結器排除既有連結、表單、程式碼、地圖標題與卡片自身地圖，但保留可見 metadata 中的地圖提及；若角色連結把一句話切成多個 DOM text node，地圖語境判斷仍以完整父元素文字與精確 occurrence offset 為準。「金澤研究所」以單次提及附近的動詞、緊鄰「地圖／關卡／流程」後綴、「區域／地點／場所／場景」metadata 前綴或「在⋯開始遊戲」句型判斷，只連結明確關卡語境，避免把所長、贊助者、研究人員或遠處的「流程會議」誤連成地圖。
